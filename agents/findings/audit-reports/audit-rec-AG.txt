AudTable: the Doppler pitch is always 1.0 (confirmed). fn_800A7CA4 (AudTable.c:80) stores pSource->fDist = nearest before it calls fn_800A7F2C. fn_800A7F2C then computes 32 * (pSource->fDist - nearest) = 0, so the pitch is 345/345 for every 3D sound. This is an EA ordering bug, and the Doppler effect is dead in the shipped game. Keep it for parity.
2. UFstPart fn_80099758 uses its new memory before the NULL check (confirmed). In the n54 < 0 branch, fn_80036054(&pEmitter->mesh) runs on fn_80009B34's result (UFstPart.c:443) before the NULL test at :453. A failed allocation would crash in the mesh init.
3. LLTexGrp: adding a texture bank never checks for a full slot table (confirmed). fn_800106F0 does not test fn_8001013C's -1. With all 100 slots in use, it writes pBank/n8/n4 into pSlots[-1], 12 bytes before the array. That path is reached through fn_80010180 ('txf ' objects), fn_800107C0 (fe_movies, Trax) and LLDynTex.
