# EA name proposals from TW07 and TW06

`name-pairing.tsv` proposes an EA name for 1,917 of our unnamed functions, generated by
`tools/naming/pairnames.py` (its docstring has the full method). These are proposals, not names: a
name is applied only after someone reads the function and agrees, through `tools/naming/name.py`.

## How it pairs

CodeWarrior emits a file's functions in source order, and TW07's debug build lists each file's
functions in source order too. Functions that already carry an EA name anchor each of our files to
its TW07 (or TW06) file. Every unnamed function between two anchors is scored against the free
reference functions in the same gap: parameter count and kinds, return kind, size, inlined callees,
paired callers, EA strings, and agreement with [`tw06-names.md`](tw06-names.md). An ordered alignment
inside each gap then picks the pairs.

## Confidence

| Grade | Rows | Meaning | Measured precision |
|---|---:|---|---|
| A | 197 | position, signature and size agree, most inside a run of pairs | 99-100% |
| B | 375 | position plus an agreeing signature and a second line of evidence | 91-97% |
| C | 1,345 | the alignment's best guess | about 63% |

Precision was measured by hiding half of the already-named functions and re-running the pairing
(three seeds), and by reading 30 random A/B pairs by hand (one wrong). A C row is a lead for the
reader, never a name by itself.

Where it fails: neighbours with the same signature in a wide gap; files TW07 rebuilt as C++ classes
(the game modes, the Apt front end, `DynTex::`); functions TW07 inlined everywhere; and GameCube-only
code (`*_Gc`, `hws*`, the shaders), which has no PS3 counterpart.

## Columns

`address unit current_name proposed source ref_file ref_line ref_signature our_signature codes
confidence score margin gap round`

- `ref_line`: the TW07 source line, or the EA_DASH address for TW06 PS2.
- `gap`: ours:theirs functions in the aligned gap. `round`: the pass in which an A/B row was
  accepted (A/B rows anchor the next pass).
- `codes`: `E2b` TW07 name, `E2` TW06 name, `E1` EA's text, then the tool's own: `sig`/`sigw`/`sig~`/
  `sig!` (signature agrees, widths agree, loosely, disagrees), `size`/`size~`/`size?`/`size!`,
  `inl<n>`, `nbr` (a neighbour pairs), `p07h/m/l` (TW07's pair list agrees), `pos=` (anchored on
  both sides, one side or none), `run<n>`, `coh`, `weak`, `dup`, `era` (a system TW2004 doesn't
  have).
