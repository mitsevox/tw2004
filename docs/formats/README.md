File formats
============

Inventory of the data on the two `GW4E69` discs. Nothing here is reverse-engineered
yet; this is the starting map. One page per format gets added as it is understood.

Containers and file types
-------------------------

| Extension | Disc 1 | Disc 2 | Seen in | Status |
|-----------|-------:|-------:|---------|--------|
| `.hog`    | 198 | 171 | course folders under `Data/` (one per hole, 1.8-5.8 MB) | `CTRL` stream container, see [ctrl-container.md](ctrl-container.md) |
| `.gcb`    | 120 | 120 | disc root (`glbdata`, `glbchar`, `fechar`, `startup`, `loadonce`, `malesac`, `femsac`) and `Data/` | same `CTRL` container as `.hog` |
| `.sac`    | 34  | 34  | `Data/charstrm/AnimChar`, `AnimGlob` (character animation) | little-endian header, no magic; not yet understood |
| `.fxg`    | 32  | 32  | `Data/charstrm/CharTex` (`NNalltex.fxg`, ~1.2-1.5 MB each) | no header, looks like raw texture data |
| `.ngc`    | 5   | 5   | `Data/movies` | `DSPM` chunks; the same stream reader handles them |
| `.sab`    | 1   | 1   | `audiostm_gc.sab` at disc root, 463 MiB | no header; audio stream |

Survey output (headers, cross-disc diff): [survey.md](survey.md), generated by
`tools/research/asset_survey.py`.

Counts are for `Data/` recursively, except `.sab`.

Course folders
--------------

| On both discs | Disc 1 only | Disc 2 only |
|---------------|-------------|-------------|
| `01_peb` `03_saw` `04_vol` `09_bay` `10_for` `11_spy` `12_pop` `17_sah` `18_jpn` `20_kap` | `02_pri` `08_dri` `13_hig` `14_sco` `15_tor` `16_sai` | `06_bet` `07_bir` `19_aus` `21_pin` |

Every file present on both discs is byte-identical except `opening.bnr` (the banner). Course
folders on both discs are only partially duplicated: `01_peb` has all 18 holes on disc 1 and 2
extra files on disc 2, and so on (see the survey).

Other `Data/` folders (both discs): `chars`, `charsac`, `charstrm`, `fechars`, `Fend`, `load`, `movies`.
